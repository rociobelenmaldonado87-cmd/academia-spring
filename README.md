# Academia Spring

Aplicación web desarrollada con Spring Boot para gestionar estudiantes y cursos.

## Funcionalidades

- Inicio de sesión y control de acceso.
- Registro y administración de estudiantes.
- Registro y administración de cursos.
- Formularios para crear y editar información.
- Persistencia de datos.

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring MVC
- Spring Security
- Thymeleaf
- Maven
- Eclipse

## Aprendizaje

Este proyecto me permitió conocer el funcionamiento de Spring Boot, organizar una aplicación en diferentes capas y crear páginas conectadas con la lógica del programa. Fue un proceso complejo, pero me ayudó a avanzar y comprender mejor el desarrollo de aplicaciones web con Java.
